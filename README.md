# VIS104 · Digital Design I

Aven-Le Zhou’s course overview for Fall 2026. It links to three separate component sites.

## Preview

Open `index.html` in a browser. Its styles and images are embedded. The component sites and artwork sources require internet access.

## GitHub Pages

Upload `index.html` and `.nojekyll` to the course overview repository’s publishing root. The third component uses its own repository, `robotic-drawing-vis104-26f`. [Robotic Drawing and Material Exploration](https://www.aven.cc/robotic-drawing-vis104-26f/)
